5. How to roll it out

  • One change per site: the strategy settings first. The seo model needs a new training config per site (about an hour), so add it second if wanted.
  • Re-check the latest two days right before changing a site. Skip it if it has turned positive.
  • Hold each site 3 full days before any further change, then judge it the same way as above.
  • Keep the user ID model out of these sites for now, so each result can be read on its own.
  • "Loose match" sites are the least certain. Do the close matches first.
How this is measured

Winners. Gap = floored vs control Prebid revenue per pageview (Venatus measurement). Effect = change in the site's gap minus the change on unchanged sites over the same days; clear needs at least 2 days after and a move at least twice the site's normal daily swing.

Matching. Five groups from our own analytics (Rill, Oct 20–28), each as a share of revenue: device (desktop, Chromebook, iOS phone, Android phone, tablet), country (US, UK, Canada, Australia, rest of Europe, rest of world), browser (Chrome, Safari, Edge, other), CPM, and pages per session. Each group is scored 0 (same) to 1 (nothing alike); CPM counts 10x apart as 1, pages per session 3x apart as 1. The five scores are combined with equal weight. Close = under 0.2, loose = 0.2–0.3. A site is held if its closest profile is a setup that lost, if no winner is within 0.3, or if under 20% of its revenue is US (floors only run on US traffic). Traffic mix is used only for matching, never for results.

Money. Behind / day = Week 2 floored revenue below what the same pageviews earned at the control rate. The added range assumes half to all of the smaller clear winner's gain, applied to floored pages (about 80%).
